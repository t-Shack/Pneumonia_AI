HOW THE SYSTEM WORKS

1

Upload

Provide a chest X-ray image (JPEG or PNG).

2

Preprocessing

The image is resized and normalized to match the model's training pipeline.

3

Feature Extraction

A convolutional neural network extracts radiographic features layer by layer.

4

Prediction

The network classifies the image as Normal or Pneumonia.

5

Result & Explanation

Confidence score, probability breakdown, and a Grad-CAM heatmap are displayed.

ABOUT THE AI MODEL

Architecture

DenseNet121, pretrained on ImageNet and fine-tuned on chest radiographs via transfer learning, with a lightweight classification head.

Preprocessing

Images are resized to 224×224 and normalized using the same ImageNet statistics the backbone was originally trained with.

Purpose

Automated screening support for chest radiographs, evaluated for accuracy, generalization to an independent dataset, and robustness to image quality degradation.

This system is a clinical decision-support tool, not a replacement for professional medical diagnosis. All predictions should be confirmed by a qualified healthcare professional.
